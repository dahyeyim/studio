# **App Name**: SeminarSync

## Core Features:

- Attendee Information: Display attendee profiles, including names, affiliations, and contact details.
- Presentation Order: Show the scheduled presentation order, presenter names, and presentation titles.
- Presentation Material Downloads: Provide secure links to download presentation slides and supporting materials.
- Real-time Question Submission: Enable attendees to submit questions during presentations via a real-time interface.
- AI-Powered Question Prioritization: Use AI to prioritize incoming questions based on relevance, sentiment, and frequency using an AI tool.

## Style Guidelines:

- Primary color: Deep blue (#293B5F) to convey trust and professionalism.
- Background color: Light gray (#E7E5EA), a very desaturated tone of the primary color, for a clean, modern look.
- Accent color: Muted purple (#7149C6), analogous to the deep blue, for interactive elements and key actions.
- Body and headline font: 'Inter', a grotesque-style sans-serif, to maintain a modern and neutral appearance suitable for a professional context
- Use clear, minimalist icons for navigation and key actions.
- Employ a clean, grid-based layout to organize information effectively.
- Subtle animations on button hover and page transitions to enhance user experience.
